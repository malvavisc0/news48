Fact-checked news, refreshed every 48 hours

news48 fetches your feeds, rewrites stories for clarity, checks claims against live evidence, and removes everything after 48 hours. No subscription, no archives. Just relevant information, verified and ready.

Feed URLs are loaded once. From there, autonomous agents take over — pulling RSS entries, downloading full content, parsing via LLM into structured data, verifying claims against live evidence, and purging everything older than 48 hours. The cycle repeats indefinitely.

self-learning

# Run 1
Executor fails → timeout too short
→ saves lesson: "use 600s timeout for fact-checks"

# Run 2
Executor starts with lesson already loaded
→ applies 600s timeout → succeeds

Agents save lessons when they discover something useful. On the next run, all accumulated lessons are injected into every agent's context. They get smarter over time — stored in SQLite, cross-pollinated across agents, and human-auditable.

get started

Deploy your own news pipeline in minutes. No vendor lock-in, no data sent to third parties, no limits. The system starts, schedules itself, and runs indefinitely on your hardware. 

# One-line install
curl -fsSL https://raw.githubusercontent.com/malvavisc0/news48/master/scripts/install.sh | bash

# Or with Docker
git clone https://github.com/malvavisc0/news48 && cd news48
docker compose up -d

The installer adds a news48 CLI to your PATH. After installation, try news48 stats, news48 feeds list, or news48 briefing.
